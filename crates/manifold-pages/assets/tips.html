Quick tips

A few gestures and shortcuts worth knowing early on. Hover any card to see what it does.

ClickSelect a card (Ctrl+click adds or removes one)
Double-clickOpen a card: a tab opens full size, a note edits, a group or JSON file steps in
Right-clickA card's menu, or the canvas's to add a tab, note or group
Right-dragSelect every card in a rectangle, then group or close them from the toolbar
Hold CtrlShow the shortcuts, and a number on each card to jump to it
Ctrl+TNew tab
Ctrl+Shift+GNew group
Ctrl+GToggle Tab / Graph view
Ctrl+KQuick switcher — jump to any open tab
Ctrl+Shift+TReopen the last closed tab
F1Full keyboard shortcut reference
