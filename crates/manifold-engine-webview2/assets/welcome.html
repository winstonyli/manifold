Manifold

Your tabs, as a graph — not a strip.

Graph, not a strip

Tabs are nodes you can drag, group, and connect — not a shrinking row of icons. Opening a link from a tab draws an edge to its parent, so your browsing history is a visible tree, not a stack you have to remember.

Groups, nested as deep as you need

Drag tabs into a group to collapse them into one card; drag a group onto another to merge them. Color-tag anything for at-a-glance organization.

Four engines, one browser

Every tab can run on Servo, CEF, WebKit, or WebView2 — pick per tab, or open "Split" to compare the same page across two engines side by side. (This page itself only renders on WebView2 — switching this tab's engine will break it, though any other tab is unaffected.)

Not just tabs

Notes, images, PDFs, and JSON files live on the same graph as your tabs — drag one into a group with related tabs instead of hunting through a separate downloads list.

Try it: expand a JSON file into the graph

Right-click any JSON node → "Expand as Graph" to explode its structure into real, draggable, nested nodes instead of a flat popup viewer.
