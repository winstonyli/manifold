Sans survey, with some character

The same two bars in 16 open-licence (OFL) sans faces, all on Google Fonts, so this page needs a network connection and you should open it in a normal browser. Literata is the first row for reference. Sorted roughly from neutral (Inter) to idiosyncratic (Bricolage, Space Grotesk, Familjen). All 13 px; check how the "New Tab" label, "145%" and the field text sit beside the icons.
