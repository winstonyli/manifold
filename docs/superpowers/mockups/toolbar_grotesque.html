Grotesque shortlist

Four grotesques in the same controls, now with menus, a settings dialog, a card header beside Literata body text, shortcut hints, a tooltip, a size ladder and numerals. Needs a network connection (Google Fonts); open in a normal browser. The buttons switch the control size (12/13/14 px). Literata first, for reference.
