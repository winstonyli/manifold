Tradeoff: airy reads calmer and more "document," but costs real estate — settings/dialogs need more scrolling, and the graph view's own toolbar (already fairly packed with icons) would need to stay compact regardless since it's screen-space-constrained. A middle path is to apply airy spacing to dialogs/settings/menus only, and leave the graph canvas's own toolbar/node chrome at today's tighter numbers.
