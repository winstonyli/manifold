# Move Undo and Redo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline; the three tasks share one new module and run in order). Steps use checkbox (`- [ ]`) syntax.

**Goal:** One session-local undo/redo history that covers Join, GroupWith, Eject, Reparent (new) and Dissolve, Ungroup All, Merge (moved onto it), reachable from a toast button and Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y.

**Architecture:** A new `crates/manifold/src/undo.rs` holds `UndoHistory` (two bounded lists, a never-reused serial) and `impl App` with `record_undo`, `step_history` and `replay`. Drops are recorded by diffing the mirror's group, parent and pos around `apply_drop`'s effect, so no per-effect snapshot code exists. Every revert goes through `edit_group` / `edit_parent` / `edit_pos`, each card guarded by a compare-and-swap against the values the drop wrote.

**Tech Stack:** Rust, egui 0.36.2, the existing `closed.rs` rig tests (`app_on`, `group_with_note`, `note`, `add_group`), `crates/gate`.

**Spec:** `docs/superpowers/specs/2026-10-19-move-undo-design.md` (approved 2026-10-19). Rulings it records: plain moves are not on the history; every effect drop shows a toast; depth 10; redo exists, cleared only by a fresh record; a fold redo folds the group as it is now.

- `cargo fmt --all` before each commit; `cargo clippy -j 8 -p manifold -p gate --all-targets -- -D warnings` must pass; never `--no-verify`.

## Review Focus

- A drop that moves a selection (several cards) reverts every card, including cards whose position changed.
- Undo then redo returns to the post-drop state for each effect (the cards, and GroupWith's group id).
- A card moved again, closed or regrouped remotely after the drop is skipped, not overwritten, and the toast says how many were restored.
- A revert never creates a new history entry or clears `redo`; a fresh drop does.
- Ctrl+Z does nothing in Tab view, with a text field focused, or with a menu or popup open.

```rust
//! Session-local undo and redo of drops and folds. Docs: `docs/superpowers/specs/2026-10-19-move-undo-design.md`.
//! In memory only: not saved, not synced. A revert is an ordinary edit through `edit_group`, `edit_parent` and
//! `edit_pos`, so other devices see it as one.

use super::*;

/// How many steps the history keeps, each way.
pub(crate) const UNDO_DEPTH: usize = 10;

/// One card a drop changed: each field's (before, after).
#[derive(Clone, Debug, PartialEq)]
pub(crate) struct Moved {
    pub(crate) id: String,
    pub(crate) group: (Option<String>, Option<String>),
    pub(crate) parent: (Option<String>, Option<String>),
    pub(crate) pos: (Option<egui::Vec2>, Option<egui::Vec2>),
}

pub(crate) enum UndoKind {
    /// A drop with an effect (Join, GroupWith, Eject, Reparent). `created` is the group a GroupWith made.
    Revert { moved: Vec<Moved>, created: Option<String> },
    /// Dissolve, Ungroup All, Merge: each group and where `fold_group` sent its members. Undo reopens the groups,
    /// redo folds them again.
    Fold(Vec<(String, Option<String>)>),
}

pub(crate) struct UndoEntry {
    pub(crate) serial: u64,
    pub(crate) message: String,
    pub(crate) kind: UndoKind,
}

#[derive(Default)]
pub(crate) struct UndoHistory {
    undo: Vec<UndoEntry>,
    redo: Vec<UndoEntry>,
    next: u64,
}

impl UndoHistory {
    /// A fresh step: onto `undo`, and nothing left to redo.
    pub(crate) fn record(&mut self, message: String, kind: UndoKind) -> u64 {
        self.next += 1;
        self.redo.clear();
        self.undo.push(UndoEntry { serial: self.next, message, kind });
        if self.undo.len() > UNDO_DEPTH {
            self.undo.remove(0);
        }
        self.next
    }

    /// Takes entry `serial` (the newest when `None`) off `redo` when `from_redo`, else off `undo`.
    pub(crate) fn take(&mut self, serial: Option<u64>, from_redo: bool) -> Option<UndoEntry> {
        let list = if from_redo { &mut self.redo } else { &mut self.undo };
        let at = match serial {
            Some(serial) => list.iter().position(|e| e.serial == serial)?,
            None => list.len().checked_sub(1)?,
        };
        Some(list.remove(at))
    }

    /// Puts an entry `take` gave from `undo` onto `redo` (`to_redo`), or one from `redo` back onto `undo`.
    pub(crate) fn put(&mut self, entry: UndoEntry, to_redo: bool) {
        let list = if to_redo { &mut self.redo } else { &mut self.undo };
        list.push(entry);
        if list.len() > UNDO_DEPTH {
            list.remove(0);
        }
    }
}
```

```rust
impl App {
    /// A new step: remembers it and offers its Undo in a toast.
    pub(crate) fn record_undo(&mut self, message: String, kind: UndoKind) {
        let serial = self.undo.record(message.clone(), kind);
        self.toasts.undo = Some((message.clone(), serial, false));
        self.queue_toast(message);
    }

    /// Undoes (or, with `redo`, redoes) entry `serial`, the newest when `None`, and offers the way back in a toast.
    /// An entry that restored nothing is dropped: its cards have all moved on.
    pub(crate) fn step_history(&mut self, serial: Option<u64>, redo: bool) {
        let Some(entry) = self.undo.take(serial, redo) else { return };
        let (done, total) = self.replay(&entry.kind, redo);
        let verb = if redo { "Redone" } else { "Undone" };
        let message = match (done, total) {
            (0, _) => format!("Nothing to {}: it has changed since", if redo { "redo" } else { "undo" }),
            (d, t) if d == t => format!("{verb}: {}", entry.message),
            (d, t) => format!("{verb} {d} of {t}: {}", entry.message),
        };
        if done > 0 {
            let serial = entry.serial;
            self.undo.put(entry, !redo);
            self.toasts.undo = Some((message.clone(), serial, !redo));
        }
        self.queue_toast(message);
        self.save_session();
    }

    /// Applies `kind` one way; returns how many of its parts took effect and how many there were.
    fn replay(&mut self, kind: &UndoKind, redo: bool) -> (usize, usize) {
        match kind {
            UndoKind::Fold(groups) => self.replay_fold(groups, redo),
        }
    }

    /// Undo reopens each group (`reopen_node`, which puts back the members still where the fold sent them); redo
    /// folds each again as the group is now, if it and its destination are shown.
    fn replay_fold(&mut self, groups: &[(String, Option<String>)], redo: bool) -> (usize, usize) {
        let mut done = 0;
        for (group, dest) in groups {
            if redo {
                if self.nodes.contains_key(group) && dest.as_ref().is_none_or(|d| self.nodes.contains_key(d)) {
                    self.fold_group(group, dest.clone());
                    done += 1;
                }
            } else if let Ok(node) = group.parse() {
                self.reopen_node(node);
                done += 1;
            }
        }
        (done, groups.len())
    }
}
```

```rust
    /// Undo puts each card back to its before values, redo to its after values, but only a card that still holds
    /// the values being left (`regroup_held`'s rule): a card moved again, closed or changed remotely is skipped.
    fn replay_revert(&mut self, moved: &[Moved], created: Option<&str>, redo: bool) -> (usize, usize) {
        // A redo of a GroupWith brings the made group back first.
        if let (true, Some(group)) = (redo, created) {
            if !self.nodes.contains_key(group) {
                if let Ok(node) = group.parse() {
                    self.reopen_node(node);
                }
            }
        }
        let side = |pair: &(Option<String>, Option<String>), after: bool| if after { pair.1.clone() } else { pair.0.clone() };
        let mut done = 0;
        for m in moved {
            let (leaving_after, arriving_after) = (!redo, redo);
            let holds = self.nodes.contains_key(&m.id)
                && self.mirror.group(&m.id).map(str::to_owned) == side(&m.group, leaving_after)
                && self.mirror.parent(&m.id).map(str::to_owned) == side(&m.parent, leaving_after)
                && self.mirror.pos(&m.id) == if leaving_after { m.pos.1 } else { m.pos.0 };
            if !holds {
                continue;
            }
            let (group, parent) = (side(&m.group, arriving_after), side(&m.parent, arriving_after));
            if let Some(p) = &parent {
                if self.would_create_cycle(&m.id, p) {
                    continue;
                }
            }
            if m.group.0 != m.group.1 {
                self.edit_group(&m.id, group);
                self.recheck_edge_scope(&m.id);
            }
            if m.parent.0 != m.parent.1 {
                self.edit_parent(&m.id, parent);
            }
            if m.pos.0 != m.pos.1 {
                self.edit_pos(&m.id, if arriving_after { m.pos.1 } else { m.pos.0 });
            }
            done += 1;
        }
        // An undone GroupWith closes the group it made once nothing is left in it.
        if let (false, Some(group)) = (redo, created) {
            if self.nodes.contains_key(group) && self.members_of(group).next().is_none() {
                self.close_node(group);
            }
        }
        (done, moved.len())
    }
```

`leaving_after` is true for an undo (it leaves the drop's *after* values). `would_create_cycle` is checked on both directions (an undo's old parent can also have become a descendant).
