# Trail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Back and Forward become one traversal. Inside a tab they walk the tab's pages, kept as a tree so pages left by navigating from the middle stay reachable as branches. At the start of a tab's pages, Back goes to the card the tab was opened from, and Forward there returns to the tab. No navigation creates a card.

**Architecture:**
- **The tree.** `nav_history.rs` is rewritten as a tree arena:
  - `entries: Vec<Entry { url, title, parent, fwd }>` and a cursor `at`;
  - a shadow of the engine's linear list, `lin: Vec<Option<usize>>` and `lin_at`;
  - one pending `Move`, committed when the engine reports its arrival;
  - a `fresh` flag, MAX_ENTRIES eviction with a protected set, and the new `tab-history.json` format.
  - The `hosted` flag, the window `capped` and the old `Saved { entries: Vec<String>, index }` are deleted.
- **Persistence.** A closed tab keeps its tree: `hide_node` stashes and re-inserts it, and the save keeps any id live in the document (`session_sync::keep_trail`). A session replace clears the trees.
- **Opened-from.** A new `trail_nav.rs` owns Back/Forward dispatch (`navigate_history`) and the chips' enablement (`trail_enabled`):
  - Back at the root resolves the parent (`mirror.parent`, then the document);
  - it reopens closed ancestors and focuses or selects the parent;
  - it records `left_to` on a tab parent, so Forward there returns to the child.
- **UI.** The Back and Forward chips get a branch marker that opens a list of sibling or child entries. A row click is a plain move (`go_to`); the row's context menu has "Open as card" (`spawn_tab_from`).
- **Gate.** EXPORTSTATE gains `trail`. A new gate stage `trail` drives the flow end to end.

**Tech Stack:** Rust 2021 on the pinned nightly; egui 0.36 (`Response::context_menu`, `ui.close()`, `egui_phosphor::light::CARET_DOWN`); serde/serde_json; the manifold store (`store::journal::Journal`, `store::model::{Doc, Node, NodeId, FieldValue, field::PARENT}`); and the `gate` crate (headless instances over stdin, `http::Server`).

**Spec:** `docs/superpowers/specs/2026-10-14-trail-design.md` (12 decisions, commit `fc14a0d`). Executors read both.

## Deviations from the spec's wording (same behaviour, fewer concepts)

- **D1. The 4b candidate is stateless.**
  - **Spec:** step 4b keeps `Option<(Dir, url, deadline)>`, cleared by `go()`, `view_reset`, commits, forks, other URLs and its deadline.
  - **Plan:** a `loading` report that fits an inferred Back or Forward is *held*: `fold` returns `false` and changes nothing, `loading` included. A settled report decides from `at`, `lin` and `fwd` alone.
  - **Why it is equivalent:** the spec itself says the candidate "only suppresses the fork of the held loading report; a settled report ... decides the same way with or without a live candidate", and a held report changes nothing for the candidate to undo. Every clearing rule is therefore moot. Tests `a_held_report_then_a_repeat_or_a_late_settled_report` and `go_while_a_report_is_held_moves_as_usual` pin it.
- **D2. `observe(url, title, loading, can_go_forward, now)` takes no `can_go_back`.** The spec's 4b ends "`observe` takes the report's `can_go_back` and `can_go_forward`", but no rule reads `can_go_back`: Back resolution reads `can_go_forward`, and so does Forward. Passing an unused flag would fail clippy (`unused_variables`).
- **D3. `go_to(entry, now)` takes no engine flags and is always plain.**
  - Decision 3 says the sibling pick "builds the same plain move"; decision 4 says `go_to` takes `can_go_*` "to choose native or plain".
  - A sibling is never the engine's neighbour (the engine's neighbour is the parent), and a Forward-chip pick from the list is a branch choice. So decision 3 wins and the flags would be dead.
- **D4. Back at the root is the App's decision.** `NavHistory::go(Back)` returns `NavAction::None` at the root. `App::navigate_history` (`trail_nav.rs`) checks `can_go_back()` and otherwise runs the opened-from step. The tree has no tab ids, as decision 1 wants.
  - While any move is pending, `navigate_history` ignores both buttons, the opened-from step included.
- **D5. Task order differs from the brief's.**
  - The new `tab-history.json` format and the minimal caller rewiring (`event_loop`, `tab_view`, `spawn_result`) go into Task 1 with the tree. The old `Saved` type cannot stay beside the new tree, and the callers cannot compile against the old signatures.
  - App-level persistence is Task 2.
- **D6. `left_to` is cleared at every cursor change the tree makes:** a commit (any move), a fork, a reused child and a J5 push. All of these run through `commit` or `child_or_push`. The spec says "at the commit of any move, and at any fork".
- **D7. The Back branch list excludes the cursor entry.** It lists the cursor's siblings, so the marker shows exactly when the list is non-empty. The Forward list shows all of the cursor's children.
- **D8. A redirect rewrite clears the entry's title.** The old title belonged to the old URL; the next report with a title fills it in (decision 11).
- **D9. The branch marker is `egui_phosphor::light::CARET_DOWN`,** an icon already used in this crate, as a small chip button right after Back (and after Forward).
- **D10. EXPORTSTATE's `trail` carries more than the spec lists.** Besides the entry count, cursor depth, fork flags and `lin_at`, it gives `url`, `lin_len`, `left_to`, `back` and `forward` (the chips' enablement), so the gate stage can find tab B and check opened-from.
- **D11. Decision 5's mention of `capped` now means the load eviction.** Decision 5(b) says a root cursor moves "only when `capped` trims a loaded file", and decision 10 deletes `capped`. In the plan, `load_from` runs `evict_to(MAX_ENTRIES)`, which is that case.
- **D12. `reopen_node`'s toasts stay.** When the opened-from step reopens a parent on another level, `reopen_node` toasts "Reopened in ..." and the step then moves to that level. The toast is accurate, so it is kept rather than special-cased away.
- **D13. `pending_trail_focus` is also cleared by `focus_tab`.** It is cleared by `forget` and `reset` as well. An explicit focus by the user wins over a reopen still landing.
- **D14. The order for a non-tab parent.** If the Item view is showing, `leave_to_graph()` runs first, then `show_level_of(parent)`, then `interaction.selected = {parent}`. `focused` is not touched. `switch_group_level` clears the selection, so the selection comes last.
- **D15. A deleted child is handled by validation on use, not eager clearing.** `left_to_child` checks liveness and the opened-from walk on every read (enablement, Forward), and Forward clears a stale value. Eager clearing at delete time would need a scan of every tree per delete for the same outcome.
- **D16. The walk cannot pass a remotely deleted parent.**
  - **Code:** `OpBody::Delete` sets `deleted = true` and clears `fields` (`crates/manifold/src/store/ops.rs:101-109`). A deleted node keeps no `PARENT`, so the spec's "while p is not live, p = that node's own `PARENT`" stops at it.
  - **Local delete:** reparents the children first (`drop_tab`, `drop_node` via `edit_parent`), so the grandparent case works.
  - **Remote delete of a shown parent:** `drop_tab` (`tabs.rs:833-844`) also reparents a shown parent's children, so Back reaches the grandparent.
  - **Delete of a closed or never-shown parent** (a remote delete, or an eviction past `MAX_CLOSED`): the node is not shown, nothing reparents, its fields are cleared, and the child's `PARENT` dangles, so Back is disabled even though a live grandparent exists. Known limit, recorded in the spec in Task 5 (parked: keep the old `PARENT` on a deleted node).
  - Test `a_remote_delete_of_the_parent_disables_back` pins this: it closes the parent first, then applies the remote `Delete`.

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::store::testutil::temp_dir;

    fn visit(h: &mut NavHistory, urls: &[&str], now: Instant) {
        for url in urls {
            h.observe(url, "", true, false, now);
            h.observe(url, "", false, false, now);
        }
    }

    fn urls(h: &NavHistory) -> Vec<&str> {
        h.entries.iter().map(|e| e.url.as_str()).collect()
    }

    fn parents(h: &NavHistory) -> Vec<Option<usize>> {
        h.entries.iter().map(|e| e.parent).collect()
    }

    /// A native Back the engine completes: one settled report at the parent's URL, Forward now possible.
    fn back(h: &mut NavHistory, now: Instant) {
        assert_eq!(h.go(Dir::Back, true, false, now), NavAction::GoBack);
        let parent = h.entries[h.at].parent.unwrap();
        let url = h.entries[parent].url.clone();
        h.observe(&url, "", false, true, now);
    }

    /// A tree built by hand: `(url, parent, fwd)` per entry, cursor `at`, no `lin`.
    fn tree(spec: &[(&str, Option<usize>, Option<usize>)], at: usize) -> NavHistory {
        let entries =
            spec.iter().map(|&(url, parent, fwd)| Entry { url: url.into(), title: String::new(), parent, fwd }).collect();
        NavHistory { entries, at, ..NavHistory::default() }
    }

    #[test]
    fn the_fork_rule_reuses_an_equal_child_and_otherwise_adds_a_sibling() {
        let now = Instant::now();
        let mut h = NavHistory::default();
        visit(&mut h, &["a", "b"], now);
        back(&mut h, now);
        visit(&mut h, &["c"], now);
        assert_eq!(urls(&h), ["a", "b", "c"]);
        assert_eq!(parents(&h), [None, Some(0), Some(0)]);
        assert_eq!((h.at, h.lin.clone(), h.lin_at), (2, vec![Some(0), Some(2)], 1));
        back(&mut h, now);
        visit(&mut h, &["b"], now);
        assert_eq!(h.entries.len(), 3, "an equal child is reused");
        assert_eq!((h.at, h.entries[0].fwd), (1, Some(1)));
    }

    #[test]
    fn a_redirect_on_an_entry_with_children_adds_a_child_in_the_same_lin_slot() {
        let now = Instant::now();
        let mut h = NavHistory::visited(&["a", "b"]);
        back(&mut h, now);
        assert!(h.fresh, "a commit marks the target fresh");
        h.observe("a", "", false, true, now);
        assert!(!h.fresh, "a later settled report clears it");
        h.observe("a", "", true, true, now);
        h.observe("a2", "", true, true, now);
        assert_eq!(urls(&h), ["a", "b", "a2"]);
        assert_eq!((h.at, h.entries[2].parent, h.entries[0].fwd), (2, Some(0), Some(2)));
        assert_eq!((h.lin.clone(), h.lin_at), (vec![Some(2), Some(1)], 0), "the engine replaced its slot");
        assert_eq!(h.go(Dir::Back, true, true, now), NavAction::Navigate("a".into()), "no engine slot before a2");
    }

    #[test]
    fn a_plain_back_is_a_new_engine_navigation_and_forward_then_navigates() {
        let now = Instant::now();
        let mut h = NavHistory::visited(&["a", "b"]);
        assert_eq!(h.go(Dir::Back, false, false, now), NavAction::Navigate("a".into()), "the engine cannot go back");

        h.observe("a", "", false, false, now);
```

```rust
//! A tab's trail (spec docs/superpowers/specs/2026-10-14-trail-design.md): its pages as a tree, so Back and Forward
//! survive an engine replacement (crash restart, wake from sleep, engine swap), a close and a restart, and pages left
//! by navigating from the middle stay reachable as branches.
//!
//! Each entry has a parent (Back) and `fwd`, the child the cursor last left it for (Forward). An engine report
//! (`observe`) moves the cursor, rewrites a redirect, or forks a child. A Back or Forward (`go`) is a pending move that
//! commits when the engine reports its arrival. `lin`/`lin_at` shadow the engine's own linear list: a move uses the
//! engine's `GoBack`/`GoForward` (scroll and form state kept) only when the engine's neighbour is the tree's, else it
//! is a plain `Navigate` to the entry's URL. Back at the root is the opened-from step (`trail_nav.rs`).
//!
//! The trees are saved to `tab-history.json`, keyed by node id: machine-local, not part of the shared session store
//! (a trail changes on every navigation; the store shares only user-started URL changes).

use std::collections::{HashMap, HashSet};
use std::path::{Path, PathBuf};
use std::time::{Duration, Instant};

/// Most entries kept per tab, and most slots in the engine-list shadow.
const MAX_ENTRIES: usize = 50;
/// How long a move waits for the engine to report its arrival.
const MOVE_WINDOW: Duration = Duration::from_secs(3);

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) enum Dir {
    Back,
    Forward,
}

/// What the host sends the engine for a move.
#[derive(Clone, Debug, PartialEq, Eq)]
pub(crate) enum NavAction {
    /// The engine's own `GoBack` (its neighbour is the tree's).
    GoBack,
    GoForward,
    /// A plain load of the entry's URL.
    Navigate(String),
    None,
}

/// One page of the trail.
#[derive(Clone, Debug, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
struct Entry {
    url: String,
    title: String,
    /// Back goes here. `None` only for the root, entry 0.
    parent: Option<usize>,
    /// Forward goes here: the child the cursor last left this entry for.
    fwd: Option<usize>,
}

/// What `tab-history.json` holds for one tab.
#[derive(Debug, serde::Serialize, serde::Deserialize)]
struct Saved {
    entries: Vec<Entry>,
    at: usize,
}

impl Saved {
    /// Decision 10's load check: `at` in range, entry 0 the only root, every parent before its child, every `fwd`
    /// one of its entry's children.
    fn valid(&self) -> bool {
        let n = self.entries.len();
        self.at < n
            && self.entries.iter().enumerate().all(|(i, e)| {
                let parent_ok = match e.parent {
                    None => i == 0,
                    Some(p) => p < i,
                };
                parent_ok && e.fwd.is_none_or(|f| f < n && self.entries[f].parent == Some(i))
            })
    }
}

/// A Back, Forward or branch pick on its way: it commits when a report arrives at `target`'s URL.
#[derive(Clone, Copy, Debug)]
struct Move {
    target: usize,
    from: usize,
    /// Sent as the engine's `GoBack`/`GoForward`, not a `Navigate`.
    native: bool,
    deadline: Instant,
}

/// What a commit does to the engine-list shadow.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum LinStep {
    /// The engine moved one slot (`GoBack`/`GoForward`, or an inferred script move).
    Native,
    /// A new engine navigation: truncate after `lin_at`, push.
    Push,
    /// The engine's current slot now shows the target (a same-URL move, which sends nothing).
    Replace,
}

#[derive(Debug, Default)]
pub(crate) struct NavHistory {
    entries: Vec<Entry>,
    /// The cursor: the entry the tab shows.
    at: usize,
    /// The engine's linear list as entry indices, oldest first; `None` is a tombstone (an evicted entry's slot).
    lin: Vec<Option<usize>>,
    /// The engine's cursor in `lin`.
    lin_at: usize,
    pending: Option<Move>,
    /// The last folded report was still loading: a URL change next is a redirect.
    loading: bool,
    /// The cursor entry was chosen by a move or reloaded by a new engine, so a redirect rewrites it.
    fresh: bool,
    /// Changed since the last save.
    dirty: bool,
}

impl NavHistory {
    /// Folds in one `NavigationStateChanged` (many repeat the same URL). `title` goes to the cursor entry when it is
    /// non-empty and the report is settled or repeats the cursor's URL (decision 11).
    pub(crate) fn observe(&mut self, url: &str, title: &str, loading: bool, can_go_forward: bool, now: Instant) {
        let before = self.saved_form();
        let same_page = self.entries.get(self.at).is_some_and(|e| e.url == url);
        if self.fold(url, loading, can_go_forward, now)
            && !title.is_empty()
            && (same_page || !loading)
            && self.entries[self.at].url == url
        {
            self.entries[self.at].title = title.to_owned();
        }
        self.dirty |= before != self.saved_form();
    }

    /// What a save writes; a change in it is a change worth saving.
    fn saved_form(&self) -> (Vec<Entry>, usize) {
        (self.entries.clone(), self.at)
    }

    /// Decision 3's fold, steps 1 to 6. `false` when the report is held (step 4b, plan D1): nothing changed, not even
    /// `loading`.
    fn fold(&mut self, url: &str, loading: bool, can_go_forward: bool, now: Instant) -> bool {
        // 1: the first report makes the root.
        if self.entries.is_empty() {
            self.entries.push(Entry { url: url.to_owned(), title: String::new(), parent: None, fwd: None });
            self.at = 0;
            self.lin = vec![Some(0)];
            self.lin_at = 0;
            self.settle(loading);
            return true;
        }
        // 2: a move whose arrival never came.
        if self.pending.is_some_and(|m| now > m.deadline) {
            self.pending = None;
        }
        // 3: a pending move commits on its target's URL and waits through its origin's.
        if let Some(m) = self.pending {
            if self.entries[m.target].url == url {
                self.pending = None;
                self.commit(m.target, m.from, if m.native { LinStep::Native } else { LinStep::Push });
                self.loading = loading;
                return true;
            }
            if self.entries[m.from].url == url {
                self.settle(loading);
                return true;
            }
            self.pending = None;
            self.fresh = false;
        }
        // 4: the cursor's own URL.
        if self.entries[self.at].url == url {
            self.settle(loading);
            return true;
        }
        // 4b: page script's history.back()/forward(), inferred from the URL; a loading report's flags are stale.
        if let Some((dir, target)) = self.inferred(url) {
            if loading {
                return false;
            }
            if can_go_forward || (dir == Dir::Forward && self.lin_at + 2 == self.lin.len()) {
                let from = self.at;
                self.commit(target, from, LinStep::Native);
                self.loading = false;
                return true;
            }
        }
        // 5: a redirect of the load in progress: rewrite the entry, or (J5) branch from one that has children.
        let was_loading = std::mem::replace(&mut self.loading, loading);
        if was_loading {
            if self.fresh || !self.has_children(self.at) {
                let entry = &mut self.entries[self.at];
                entry.url = url.to_owned();
                entry.title.clear();
            } else {
                let child = self.child_or_push(url);
                self.entries[self.at].fwd = Some(child);
                self.at = child;
                self.fresh = false;
            }
            // The engine replaced its slot in place: no truncate, no push.
            if let Some(slot) = self.lin.get_mut(self.lin_at) {
                *slot = Some(self.at);
            }
            if !loading {
                self.fresh = false;
            }
            self.evict_to(MAX_ENTRIES);
            return true;
        }
        // 6: a new page: the equal child, else a new branch.
        let child = self.child_or_push(url);
        self.entries[self.at].fwd = Some(child);
        self.at = child;
        self.fresh = false;
        self.lin_push(child);
        self.evict_to(MAX_ENTRIES);
        true
    }

    /// A report that changes nothing but `loading`; a settled one ends the cursor entry's freshness.
    fn settle(&mut self, loading: bool) {
        self.loading = loading;
        if !loading {
            self.fresh = false;
        }
    }

    /// The tree's neighbour whose URL is `url` and that the engine's list holds next to its cursor (4b's candidates).
    fn inferred(&self, url: &str) -> Option<(Dir, usize)> {
        [Dir::Back, Dir::Forward].into_iter().find_map(|dir| {
            let target = self.native_neighbour(dir)?;
            (self.entries[target].url == url).then_some((dir, target))
        })
    }

    /// The cursor's parent (Back) or `fwd` (Forward) when the engine's list holds it in the adjacent slot (decision
    /// 4's guard, without the engine's flag). A tombstone never matches.
    fn native_neighbour(&self, dir: Dir) -> Option<usize> {
        let cur = self.entries.get(self.at)?;
        let (target, slot) = match dir {
            Dir::Back => (cur.parent?, self.lin_at.checked_sub(1)?),
            Dir::Forward => (cur.fwd?, self.lin_at + 1),
        };
        (self.lin.get(slot) == Some(&Some(target))).then_some(target)
    }

    /// The cursor's parent (Back) or `fwd` (Forward).
    fn neighbour(&self, dir: Dir) -> Option<usize> {
        let cur = self.entries.get(self.at)?;
        match dir {
            Dir::Back => cur.parent,
            Dir::Forward => cur.fwd,
        }
    }

    fn has_children(&self, i: usize) -> bool {
        self.entries.iter().any(|e| e.parent == Some(i))
    }

    /// A Back or Forward press inside the trail: what to send, with nothing in the tree changed until the arrival
    /// (one exception: a target whose URL equals the cursor's commits now). `can_go_*` are the engine's last-reported
    /// flags. `NavAction::None` at the root's Back, at no `fwd`, and while a move is pending.
    pub(crate) fn go(&mut self, dir: Dir, can_go_back: bool, can_go_forward: bool, now: Instant) -> NavAction {
        if self.move_pending(now) {
            return NavAction::None;
        }
        let Some(target) = self.neighbour(dir) else { return NavAction::None };
        let engine = match dir {
            Dir::Back => can_go_back,
            Dir::Forward => can_go_forward,
        };
        let native = engine && self.native_neighbour(dir) == Some(target);
        self.start(target, native, now)
    }

    fn move_pending(&self, now: Instant) -> bool {
        self.pending.is_some_and(|m| now <= m.deadline)
    }

    /// Starts a move to `target` from the cursor.
    fn start(&mut self, target: usize, native: bool, now: Instant) -> NavAction {
        let from = self.at;
        let back = self.entries[from].parent == Some(target);
        let url = self.entries[target].url.clone();
        let action = match (native, back) {
            (true, true) => NavAction::GoBack,
            (true, false) => NavAction::GoForward,
            (false, _) => NavAction::Navigate(url.clone()),
        };
        if url == self.entries[from].url {
            // No report could tell the arrival from the origin. A plain move sends nothing: the tab shows that page.
            let before = self.saved_form();
            self.commit(target, from, if native { LinStep::Native } else { LinStep::Replace });
            self.dirty |= before != self.saved_form();
            return if native { action } else { NavAction::None };
        }
        self.pending = Some(Move { target, from, native, deadline: now + MOVE_WINDOW });
        action
    }

    /// The cursor arrives at `target` from `from` (decision 3's commit).
    fn commit(&mut self, target: usize, from: usize, step: LinStep) {
        let back = self.entries[from].parent == Some(target);
        if back {
            self.entries[target].fwd = Some(from);
        } else if let Some(p) = self.entries[target].parent {
            self.entries[p].fwd = Some(target);
        }
        self.at = target;
        self.fresh = true;
        match step {
            LinStep::Native if back => self.lin_at = self.lin_at.saturating_sub(1),
            LinStep::Native => self.lin_at = (self.lin_at + 1).min(self.lin.len().saturating_sub(1)),
            LinStep::Push => self.lin_push(target),
            LinStep::Replace => {
                if let Some(slot) = self.lin.get_mut(self.lin_at) {
                    *slot = Some(target);
                }
            }
        }
    }

    /// A new engine navigation to `entry`: the engine drops its forward slots and appends one.
    fn lin_push(&mut self, entry: usize) {
        self.lin.truncate(self.lin_at + 1);
        self.lin.push(Some(entry));
        if self.lin.len() > MAX_ENTRIES {
            self.lin.remove(0);
        }
        self.lin_at = self.lin.len() - 1;
    }

    /// The cursor's child at `url`, pushed as a new child if there is none (the fork rule).
    fn child_or_push(&mut self, url: &str) -> usize {
        if let Some(c) = (0..self.entries.len()).find(|&c| self.entries[c].parent == Some(self.at) && self.entries[c].url == url) {
            return c;
        }
        self.entries.push(Entry { url: url.to_owned(), title: String::new(), parent: Some(self.at), fwd: None });
        self.entries.len() - 1
    }

    /// The tab's engine was replaced and knows only the page at `url` (decision 4). A tree whose cursor is not at
    /// `url` (the tab moved while the app was closed, or the file is stale) is emptied, and the next report makes a
    /// new root.
    pub(crate) fn view_reset(&mut self, url: &str) {
        self.pending = None;
        self.loading = false;
        if self.entries.get(self.at).is_some_and(|e| e.url == url) {
            self.lin = vec![Some(self.at)];
            self.lin_at = 0;
            self.fresh = true;
            return;
        }
        self.dirty |= !self.entries.is_empty();
        self.entries.clear();
        self.at = 0;
        self.lin.clear();
        self.lin_at = 0;
        self.fresh = false;
    }

    /// The trail itself has a Back: the cursor is not the root.
    pub(crate) fn can_go_back(&self) -> bool {
        self.neighbour(Dir::Back).is_some()
    }

    pub(crate) fn can_go_forward(&self) -> bool {
        self.neighbour(Dir::Forward).is_some()
    }

    /// Decision 5: drops entries until at most `cap` remain, each time the oldest leaf off the protected set, else
    /// (the tree is a chain) the root.
    fn evict_to(&mut self, cap: usize) {
        while self.entries.len() > cap {
            let keep = self.protected();
            let leaf = (0..self.entries.len()).find(|&i| !keep.contains(&i) && !self.has_children(i));
            let victim = match leaf {
                Some(v) => v,
                None => {
                    // A chain sorted by index: the root's only child is entry 1.
                    let Some(child) = (1..self.entries.len()).find(|&c| self.entries[c].parent == Some(0)) else {
                        return;
                    };
                    if self.at == 0 {
                        self.at = child;
                        self.fresh = false;
                    }
                    self.entries[child].parent = None;
                    0
                }
            };
            self.remove(victim);
        }
    }

    /// The root-to-cursor path and the `fwd` chain from the cursor: what Back and Forward can reach.
    fn protected(&self) -> HashSet<usize> {
        let mut keep = HashSet::new();
        let mut cur = Some(self.at);
        while let Some(i) = cur.filter(|&i| keep.insert(i)) {
            cur = self.entries[i].parent;
        }
        let mut cur = self.entries[self.at].fwd;
        while let Some(i) = cur.filter(|&i| keep.insert(i)) {
            cur = self.entries[i].fwd;
        }
        keep
    }

    /// Removes entry `v` and renumbers: a `parent`/`fwd` naming it becomes `None`, a `lin` slot naming it a tombstone.
    fn remove(&mut self, v: usize) {
        debug_assert!(self.pending.is_none(), "eviction follows a push, after step 3 dropped or committed the move");
        let shift = |i: usize| match i.cmp(&v) {
            std::cmp::Ordering::Less => Some(i),
            std::cmp::Ordering::Equal => None,
            std::cmp::Ordering::Greater => Some(i - 1),
        };
        self.entries.remove(v);
        for e in &mut self.entries {
            e.parent = e.parent.and_then(shift);
            e.fwd = e.fwd.and_then(shift);
        }
        for slot in &mut self.lin {
            *slot = slot.and_then(shift);
        }
        if let Some(at) = shift(self.at) {
            self.at = at;
        }
    }

    /// A trail that visited `urls` in order, each reported loading then settled.
    #[cfg(test)]
    pub(crate) fn visited(urls: &[&str]) -> NavHistory {
        let now = Instant::now();
        let mut h = NavHistory::default();
        for url in urls {
            h.observe(url, "", true, false, now);
            h.observe(url, "", false, false, now);
        }
        h
    }
}

fn path() -> Option<PathBuf> {
    Some(crate::profile::dir()?.join("tab-history.json"))
}

/// The saved trees. A missing file gives none; one that does not parse (the old format included) is moved aside.
pub(crate) fn load() -> HashMap<String, NavHistory> {
    path().map_or_else(HashMap::new, |path| load_from(&path))
}

pub(crate) fn load_from(path: &Path) -> HashMap<String, NavHistory> {
    let saved: HashMap<String, Saved> =
        crate::json_file::load_or_move_aside(path, "tab history").ok().flatten().unwrap_or_default();
    saved
        .into_iter()
        .filter(|(_, s)| s.valid())
        .map(|(id, s)| {
            let mut h = NavHistory { entries: s.entries, at: s.at, ..NavHistory::default() };
            h.evict_to(MAX_ENTRIES);
            (id, h)
        })
        .collect()
}

/// Drops the trees of tabs `keep` refuses, then writes the rest (one-page trees add nothing and are left out) when
/// any changed or any was dropped.
pub(crate) fn save(lists: &mut HashMap<String, NavHistory>, keep: impl Fn(&str) -> bool) {
    save_to(lists, keep, path().as_deref());
}

pub(crate) fn save_to(lists: &mut HashMap<String, NavHistory>, keep: impl Fn(&str) -> bool, path: Option<&Path>) {
    let before = lists.len();
    lists.retain(|id, _| keep(id));
    let dropped = lists.len() != before;
    if !dropped && !lists.values().any(|h| h.dirty) {
        return;
    }
    let Some(path) = path else { return };
    let saved: HashMap<&String, Saved> = lists
        .iter()
        .filter(|(_, h)| h.entries.len() > 1)
        .map(|(id, h)| (id, Saved { entries: h.entries.clone(), at: h.at }))
        .collect();
    crate::json_file::save(&saved, path, "tab history");
    lists.values_mut().for_each(|h| h.dirty = false);
}
```

```rust
//! Back and Forward for a tab (spec docs/superpowers/specs/2026-10-14-trail-design.md, decisions 6 and 7): the tab's
//! own trail (`nav_history`) first. At the root of the trail, Back goes to the card the tab was opened from
//! (reopening it if closed), and that card, when a tab, records `left_to` so its Forward returns.

use std::time::Instant;

use super::*;
use crate::nav_history::{Dir, NavAction};
use crate::store::model::{Kind, NodeId};

/// `id`'s raw `PARENT` in the document.
fn doc_parent(doc: &crate::store::model::Doc, id: &str) -> Option<String> {
    let node = doc.nodes.get(&id.parse::<NodeId>().ok()?)?;
    if let FieldValue::Id(Some(p)) = node.get(field::PARENT) {
        Some(p.to_string())
    } else {
        None
    }
}

impl App {
    /// A Back or Forward press on tab `id` (the toolbar chips, `GOBACK`/`GOFORWARD`). Ignored while a move is pending.
    pub(crate) fn navigate_history(&mut self, id: &str, dir: Dir) {
        let now = Instant::now();
        let history = self.nav_history.get(id);
        if history.is_some_and(|h| h.move_pending(now)) {
            return;
        }
        let own = history.is_some_and(|h| match dir {
            Dir::Back => h.can_go_back(),
            Dir::Forward => h.can_go_forward(),
        });
        if own {
            let Some(node) = self.nodes.get(id).and_then(|n| n.as_tab()) else { return };
            let (back, forward) = (node.can_go_back, node.can_go_forward);
            let action = self.nav_history.get_mut(id).map_or(NavAction::None, |h| h.go(dir, back, forward, now));
            self.send_nav_action(id, action);
            return;
        }
        match dir {
            Dir::Back => self.trail_back_to_parent(id),
            Dir::Forward => self.trail_forward_to_child(id),
        }
    }

    fn send_nav_action(&mut self, id: &str, action: NavAction) {
        let message = match action {
            NavAction::GoBack => HostToView::GoBack,
            NavAction::GoForward => HostToView::GoForward,
            NavAction::Navigate(url) => HostToView::Navigate { url, referrer: None },
            NavAction::None => return,
        };
        if let Some(node) = self.nodes.get_mut(id).and_then(|n| n.as_tab_mut()) {
            node.tab.send(&message);
        }
    }

    /// The chips' enablement for tab `id`: the trail's own Back, else an opened-from parent; the trail's own Forward,
    /// else a valid `left_to`.
    pub(crate) fn trail_enabled(&self, id: &str) -> (bool, bool) {
        let history = self.nav_history.get(id);
        let back = history.is_some_and(|h| h.can_go_back()) || self.trail_parent(id).is_some();
        let forward = history.is_some_and(|h| h.can_go_forward()) || self.left_to_child(id).is_some();
        (back, forward)
    }

    /// The card `id` was opened from (decision 6): its `PARENT` from the mirror (which sees an edit or a Create not yet
    /// in the document), else from the document (the mirror has no links for a hidden node); while that one is not
    /// live, its own `PARENT` from the document. `None` when no live ancestor is left (plan D16 for a remote delete).
    pub(crate) fn trail_parent(&self, id: &str) -> Option<String> {
        let doc = self.journal.as_ref().map(|j| j.doc());
        let mut p = match self.mirror.parent(id) {
            Some(p) => p.to_owned(),
            None => doc_parent(doc?, id)?,
        };
        for _ in 0..=doc.map_or(0, |d| d.nodes.len()) {
            if self.is_live_id(&p) {
                return Some(p);
            }
            p = doc_parent(doc?, &p)?;
        }
        None
    }

    /// `id` is shown (`nodes`), or live in the document (hidden by a close).
    fn is_live_id(&self, id: &str) -> bool {
        self.nodes.contains_key(id) || self.doc_node(id).is_some_and(|n| n.is_live())
    }

    fn doc_node(&self, id: &str) -> Option<&crate::store::model::Node> {
        let id: NodeId = id.parse().ok()?;
        self.journal.as_ref()?.doc().nodes.get(&id)
    }

    fn trail_is_tab(&self, id: &str) -> bool {
        self.mirror.ty(id) == crate::store::model::TYPE_TAB || self.doc_node(id).is_some_and(|n| n.kind() == Kind::Tab)
    }

    /// Back at the root of `id`'s trail: focus its parent, which, when a tab, remembers `id` for its Forward.
    fn trail_back_to_parent(&mut self, id: &str) {
        let Some(parent) = self.trail_parent(id) else { return };
        if self.trail_is_tab(&parent) {
            self.nav_history.entry(parent.clone()).or_default().set_left_to(Some(id.to_owned()));
        }
        self.trail_focus(&parent);
    }

    /// `parent`'s `left_to` while it is valid (decision 7): the child is live and its opened-from walk ends at
    /// `parent` (a grandparent Back resolved to after a delete keeps it).
    fn left_to_child(&self, parent: &str) -> Option<String> {
        let child = self.nav_history.get(parent)?.left_to()?;
        (self.is_live_id(child) && self.trail_parent(child).as_deref() == Some(parent)).then(|| child.to_owned())
    }

    /// Forward with no Forward in the trail: back to the child Back left, or, if that is stale, forget it.
    fn trail_forward_to_child(&mut self, id: &str) {
        match self.left_to_child(id) {
            Some(child) => self.trail_focus(&child),
            None => {
                if let Some(h) = self.nav_history.get_mut(id) {
                    h.set_left_to(None);
                }
            }
        }
    }

    /// Shows `id` for the opened-from step: reopens the closed nodes that hide it, outermost first (a nested closed
    /// node stays closed when its group reopens, so this repeats), then focuses it. A reopen that has not put `id`
    /// in `nodes` yet (a tab still spawning) leaves it to `poll_trail_focus`.
    fn trail_focus(&mut self, id: &str) {
        let mut last = None;
        for _ in 0..=self.journal.as_ref().map_or(0, |j| j.doc().nodes.len()) {
            let Some(root) = self.outermost_closed(id) else { break };
            if last == Some(root) {
                // The reopen did not take (a failed or read-only save leaves the flag).
                self.queue_toast("Couldn't reopen that card".to_string());
                return;
            }
            last = Some(root);
            self.reopen_node(root);
        }
        if self.nodes.contains_key(id) {
            self.finish_trail_focus(id);
        } else {
            self.spawns.pending_trail_focus = Some(id.to_owned());
        }
    }

    /// The outermost closed node on `id`'s `group` chain, `id` included, from the document.
    fn outermost_closed(&self, id: &str) -> Option<NodeId> {
        let doc = self.journal.as_ref()?.doc();
        let mut cur = Some(id.parse::<NodeId>().ok()?);
        let mut outer = None;
        for _ in 0..=doc.nodes.len() {
            let Some(c) = cur else { break };
            let Some(node) = doc.nodes.get(&c) else { break };
            if node.is_live() && node.closed() {
                outer = Some(c);
            }
            cur = node.group;
        }
        outer
    }

    /// `id` is in `nodes`: a tab or image opens in the Item view on its level; any other card is selected on its
    /// level in the Graph view (plan D14).
    fn finish_trail_focus(&mut self, id: &str) {
        let ty = self.card_kind(id).map(|k| k.ty);

        }
        self.show_level_of(id);
        self.interaction.selected.clear();
        self.interaction.selected.insert(id.to_owned());
    }

    /// Finishes a `trail_focus` once its node is in `nodes`; drops one whose node is gone. Called each tick after the
    /// store is polled.
    pub(crate) fn poll_trail_focus(&mut self) {
        let Some(id) = self.spawns.pending_trail_focus.clone() else { return };
        if self.nodes.contains_key(&id) {
            self.spawns.pending_trail_focus = None;
            self.finish_trail_focus(&id);
        } else if !self.is_live_id(&id) {
            self.spawns.pending_trail_focus = None;
        }
    }
}
```

```rust
    /// A row of the branch list (decision 8): a plain move to `target`, never native (plan D3). Ignored for the
    /// cursor entry, an index out of range, and while a move is pending.
    pub(crate) fn go_to(&mut self, target: usize, now: Instant) -> NavAction {
        if self.move_pending(now) || target == self.at || target >= self.entries.len() {
            return NavAction::None;
        }
        self.start(target, false, now)
    }

    /// The branch list for `dir`: the cursor's siblings (Back; plan D7) or its children (Forward), oldest first,
    /// each with its title, or its URL when the title is empty.
    pub(crate) fn branches(&self, dir: Dir) -> Vec<(usize, String)> {
        let Some(cur) = self.entries.get(self.at) else { return Vec::new() };
        let parent = match dir {
            Dir::Back => {
                let Some(p) = cur.parent else { return Vec::new() };
                p
            }
            Dir::Forward => self.at,
        };
        self.entries
            .iter()
            .enumerate()
            .filter(|&(i, e)| e.parent == Some(parent) && i != self.at)
            .map(|(i, e)| (i, if e.title.is_empty() { e.url.clone() } else { e.title.clone() }))
            .collect()
    }

    /// The Back chip shows its branch marker: the cursor entry has siblings.
    pub(crate) fn back_fork(&self) -> bool {
        !self.branches(Dir::Back).is_empty()
    }

    /// The Forward chip shows its branch marker: the cursor entry has more than one child.
    pub(crate) fn forward_fork(&self) -> bool {
        self.branches(Dir::Forward).len() > 1
    }

    pub(crate) fn entry_url(&self, entry: usize) -> Option<&str> {
        self.entries.get(entry).map(|e| e.url.as_str())
    }
```

```rust
//! `gate trail`: Back and Forward over a tab's pages and over opened-from, end to end (spec
//! docs/superpowers/specs/2026-10-14-trail-design.md, "Tests"). One throwaway profile seeded with tab A on a local site
//! served by this process (every page titled by its path). From A, NEWTAB opens tab B (parented to the focused tab) at
//! the home page /b1; B goes to /b2 and /b3. Back twice walks B's pages, a third Back focuses A (opened-from, and A
//! records `left_to`), Forward on A returns to B, and a new page from /b1 makes a sibling of /b2 (EXPORTSTATE
//! `trail`).
//!
//! A failing check does not stop the run; a runner error (a timeout, a launch failure) prints an `ERROR:` line, counts
//! as a failure and ends the run early. The instance is killed on every exit path (`Instance`'s Drop plus the job).

use std::io;
use std::path::PathBuf;
use std::process::{Command, ExitCode, Stdio};
use std::sync::Arc;
use std::time::Duration;

use serde_json::Value;

use crate::check::{check_is, exit_code, failures, note_failure, Section};
use crate::http::{response, Server};
use crate::instance::{log_tail, seed_settings, Instance};
use crate::link::{bad, no_verdict_words};
use crate::state::{State, TAB};

/// How long the instance may take to exit after QUIT.
const QUIT_TIMEOUT: Duration = Duration::from_secs(60);

struct Run {
    exe: PathBuf,
    work: PathBuf,
    profile: PathBuf,
    /// `http://127.0.0.1:<port>` of the site.
    base: String,
}

impl Run {
    /// Settings (home page /b1, so NEWTAB opens B there) and a session holding tab A at /a.
    fn setup(&self) -> io::Result<()> {
        seed_settings(&self.profile, "webview2", &format!(", \"home_page\": \"{}/b1\"", self.base))?;
        let seed = self.profile.join("seed.json");
        let tab = serde_json::json!({"id": "a", "type": TAB, "url": format!("{}/a", self.base), "view_kind": "webview2",
            "pos": [0.0, 0.0]});
        std::fs::write(&seed, serde_json::json!({ "nodes": [tab] }).to_string())?;
        let status = Command::new(&self.exe)
            .arg("--import-json")
            .arg(&seed)
            .arg("--out")
            .arg(self.profile.join("session.mnf"))
            .stdout(Stdio::null())
            .status()?;
        if status.success() {
            Ok(())
        } else {
            Err(io::Error::other(format!("--import-json exited with {status}")))
        }
    }

    fn go(&self, inst: &mut Instance, path: &str) -> io::Result<()> {
        inst.send(&format!("ADDRESSBAR {}{path}", self.base))?;
        inst.send("WAITIDLE")?;
        inst.send("ENTER")
    }

/// Tab `id`'s entry in EXPORTSTATE's `trail`.
fn trail_of<'a>(s: &'a State, id: &str) -> Option<&'a Value> {
    s.0["trail"].get(id)
}

/// The id of the one trail whose cursor URL ends with `path`.
fn trail_at(s: &State, path: &str) -> Option<String> {
    let trails = s.0["trail"].as_object()?;
    let ids: Vec<&String> =
        trails.iter().filter(|(_, t)| t["url"].as_str().is_some_and(|u| u.ends_with(path))).map(|(id, _)| id).collect();
    match ids.as_slice() {
        [one] => Some((*one).clone()),
        _ => None,
    }
}

fn field<'a>(s: &'a State, id: &str, key: &str) -> Option<&'a Value> {
    trail_of(s, id).map(|t| &t[key])
}

fn drive(run: &Run, sec: &mut Option<Section>) -> io::Result<()> {
    let mut next = |name: &str| *sec = sec.take().map(|s| s.next(name));
    let at = |s: &State, path: &str| s.focused_url().ends_with(path);

    next("open");
    let mut inst = Instance::launch(&run.exe, &run.profile, &run.work, "trail.log")?;
    for c in ["WAITTABS", "GRAPHRIGHT", "GRAPHOPEN", "WAITIDLE"] {
        inst.send(c)?;
    }
    let s = inst.export_until("a-open", |s| at(s, "/a") && trail_at(s, "/a").is_some())?;
    let a = trail_at(&s, "/a").ok_or_else(|| bad("tab A has no trail".to_string()))?;
    // NEWTAB leaves focus on A; NEXTTAB (creation order) moves it to B.
    for c in ["NEWTAB", "WAITTABS", "NEXTTAB", "WAITIDLE"] {
        inst.send(c)?;
    }
    let s = inst.export_until("b-open", |s| at(s, "/b1") && trail_at(s, "/b1").is_some_and(|b| b != a))?;
    let b = trail_at(&s, "/b1").ok_or_else(|| bad("tab B has no trail".to_string()))?;

    next("pages");
    for p in ["/b2", "/b3"] {
        run.go(&mut inst, p)?;
        inst.export_until(&format!("at{p}"), |s| at(s, p))?;
    }
    let s = inst.export_until("b3", |s| field(s, &b, "entries") == Some(&3.into()) && field(s, &b, "depth") == Some(&2.into()))?;
    check_is("B's trail is /b1 /b2 /b3", Some(3), field(&s, &b, "entries").and_then(Value::as_u64));

    next("back");
    inst.send("GOBACK")?;
    let s = inst.export_until("back1", |s| at(s, "/b2") && field(s, &b, "depth") == Some(&1.into()))?;
    check_is("Forward is offered on /b2", Some(true), field(&s, &b, "forward").and_then(Value::as_bool));
    inst.send("GOBACK")?;
    let s = inst.export_until("back2", |s| at(s, "/b1") && field(s, &b, "depth") == Some(&0.into()))?;
    check_is("Back at B's first page goes on (opened-from)", Some(true), field(&s, &b, "back").and_then(Value::as_bool));
    inst.send("GOBACK")?;
    let s = inst.export_until("parent", |s| at(s, "/a"))?;
    check_is("A remembers it was left for B", Some(b.as_str()), field(&s, &a, "left_to").and_then(Value::as_str));
    check_is("Forward is offered on A", Some(true), field(&s, &a, "forward").and_then(Value::as_bool));

    next("forward");
    inst.send("GOFORWARD")?;
    let s = inst.export_until("child", |s| at(s, "/b1"))?;
    check_is("Forward returned to B's page", Some(0), field(&s, &b, "depth").and_then(Value::as_u64));

    next("fork");
    run.go(&mut inst, "/b4")?;
    let s = inst.export_until("fork", |s| at(s, "/b4") && field(s, &b, "entries") == Some(&4.into()))?;
    check_is("/b4 is a child of /b1", Some(1), field(&s, &b, "depth").and_then(Value::as_u64));
    check_is("the Back chip shows the branch marker", Some(true), field(&s, &b, "back_fork").and_then(Value::as_bool));
    inst.quit(QUIT_TIMEOUT).map(|_| ())
}

pub fn trail(parent: Option<PathBuf>) -> ExitCode {
    let mut sec = Some(Section::start("setup"));
    let exe = match manifold_exe() {
        Ok(exe) => exe,
        Err(e) => {
            eprintln!("{e}");
            return ExitCode::from(1);
        }
    };
    let work = match work_dir(parent, "trail") {
        Ok(w) => w,
        Err(e) => {
            eprintln!("work dir: {e}");
            return ExitCode::from(1);
        }
    };
    let server = match Server::start(Arc::new(|line: &str| {
        let path = line.split(' ').nth(1).unwrap_or("/");
        let body = format!("<!doctype html><title>{path}</title><p>{path}</p>");
        response("200 OK", &[], "text/html", body.as_bytes())
    })) {
        Ok(s) => s,
        Err(e) => {
            eprintln!("site: {e}");
            return ExitCode::from(1);
        }
    };
    let run = Run { exe, profile: work.join("profile"), work, base: format!("http://127.0.0.1:{}", server.port()) };
    if let Err(e) = run.setup().and_then(|()| drive(&run, &mut sec)) {
        println!("ERROR: trail stopped early: {e}");
        note_failure();
    }
    if failures() > 0 {
        println!("--- trail.log\n{}", no_verdict_words(&log_tail(&run.work.join("trail.log"), 30)));
    }
    drop(sec);
    drop(server);
    if std::env::var_os("KEEP").is_none() {
        let _ = std::fs::remove_dir_all(&run.work);
    }
    exit_code()
}
```
