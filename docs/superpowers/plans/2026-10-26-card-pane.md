# Card Pane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Selecting stored cards in the Graph view shows a card pane in the right panel slot the JSON outline uses, holding the selection's labels (moved out of the selection bar's popup) and one card's name, place, jar, links and text, without moving the world.

**Architecture:** One right panel (`graph_ui/right_panel.rs`) picks the outline or the card pane from one predicate, `App::right_panel()`, which the scene-area rect also reads. The pane (`graph_ui/card_pane.rs`) only pushes existing `GraphAction`s (one card's `NodeAction`s ride `GraphAction::Node`). The camera keeps scale and left edge when only the scene area's width changes, so the panel covers a strip instead of zooming the world.

**Tech Stack:** Rust, egui 0.36.2 (`egui::Panel::right`, `Memory` focus), the workspace's `gate` crate.

**Spec:** `docs/superpowers/specs/2026-10-26-card-pane-design.md`

## Global Constraints

- Edits go only through existing `NodeAction` and `GraphAction` values (decision 3). No action is added; `GraphAction::LabelSelected` is deleted.
- The pane is an inspector: no Sleep, Copy URL, Duplicate, Close, Move into, New Jar or Pin toggle in it (decision 4).
- The world does not move or zoom when the panel opens, closes or is resized (R1).
- One width setting `right_panel_width` (App field, default `260.0`), panel range `160.0..=640.0`, never more than half the window (R4). `LocalState.json_outline_width` becomes `right_panel_width`; no migration.
- The pane never takes keyboard focus on its own (R5).
- Names: a raw `.name` read needs the file on `names/tests.rs`'s ALLOWED list and a `// name rule: <why>` comment.
- No test touches the real `%APPDATA%`.
- Before each commit: `cargo fmt --all`, and `cargo clippy -j 8 -p manifold -p manifold-view-protocol -p manifold-pages -p manifold-view-webview2 -p manifold-view-pdfium -p gate --all-targets -- -D warnings` passes (the pre-commit hook checks both; never `--no-verify`).
- Python, if ever needed: `python -P f.py < /dev/null`. Edits with the Edit tool.

```rust
    /// Grows `rect` to everything `Scene` shows of it in `outer`, keeping
    /// its center and scale. `Scene` fits `rect` into `outer` by aspect,
    /// so a rect of another shape (a fit to the cards' bounds, a tween
    /// toward one) is shown with more world beside it than it covers,
    /// and `Scene` only writes the full visible rect back after a user pan
    /// or zoom. Until then the grid, card culling, the LOD count and the
    /// minimap, which all read `rect`, skipped that margin: a card dragged
    /// into it vanished.
    ///
    /// When `outer` differs from the last area only in width, the world stays put instead (card-pane spec R1): `rect`
    /// is first fitted to the last area, then keeps that scale and left edge, so a panel on the right covers or shows
    /// a strip rather than zooming everything.
    pub(crate) fn fill(&mut self, outer: egui::Rect) {
        if !self.rect.is_finite() || !self.rect.is_positive() || !outer.is_positive() {
            return; // `Scene` resets a bad rect itself.
        }
        let last = self.area.replace(outer);
        match last.filter(|l| l.min == outer.min && l.height() == outer.height() && l.width() != outer.width()) {
            Some(last) => {
                self.fit(last);
                let scale = last.width() / self.rect.width();
                self.rect = egui::Rect::from_min_size(self.rect.min, outer.size() / scale);
            }
            None => self.fit(outer),
        }
    }

    /// `rect` refitted to `outer`'s shape about its centre, at the scale `Scene` shows it with.
    fn fit(&mut self, outer: egui::Rect) {
        let scale = (outer.size() / self.rect.size()).min_elem().clamp(GRAPH_ZOOM_MIN, GRAPH_ZOOM_MAX);
        self.rect = egui::Rect::from_center_size(self.rect.center(), outer.size() / scale);
    }
```

```rust
use super::*;

/// The right panel's narrowest and widest (before the half-window cap, R4).
const RIGHT_PANEL_MIN: f32 = 160.0;
const RIGHT_PANEL_MAX: f32 = 640.0;

/// What the right panel holds.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum RightPanel {
    /// A JSON level's outline, while it is not hidden.
    Outline,
    /// The card pane, while stored cards are selected (`card_pane`).
    Cards,
}

impl App {
    /// What the right panel shows now, if anything: a JSON level shows its outline (or nothing, hidden), any other
    /// level the card pane while stored cards are selected.
    pub(crate) fn right_panel(&self) -> Option<RightPanel> {
        if self.json_level.is_some() {
            return self.json_ui.json_outline_visible.then_some(RightPanel::Outline);
        }
        (self.selected_stored_count() > 0).then_some(RightPanel::Cards)
    }

    /// The widest the panel may be: `RIGHT_PANEL_MAX`, or half the window when that is less (R4), never under the
    /// minimum.
    fn right_panel_max(&self) -> f32 {
        (self.screen_size_points().x / 2.0).min(RIGHT_PANEL_MAX).max(RIGHT_PANEL_MIN)
    }

    /// The width the scene area gives up to the panel: none while it is hidden.
    pub(crate) fn right_panel_width_shown(&self) -> f32 {
        match self.right_panel() {
            Some(_) => self.right_panel_width.clamp(RIGHT_PANEL_MIN, self.right_panel_max()),
            None => 0.0,
        }
    }

    /// The right panel, before the canvas takes the remaining space. Also keeps the pane's state with the selection:
    /// the label section's drafts go when the pane does, and a newly described card is revealed (R2).
    pub(super) fn build_right_panel(&mut self, ui: &mut egui::Ui, actions: &mut Vec<GraphAction>) {
        let shown = self.right_panel();
        self.track_pane_card();
        let Some(shown) = shown else { return };
        if shown == RightPanel::Outline {
            self.poll_json_search();
        }
        let panel = egui::Panel::right("right_panel")
            .resizable(true)
            .default_size(self.right_panel_width)
            .size_range(RIGHT_PANEL_MIN..=self.right_panel_max())
            .show(ui, |ui| match shown {
                RightPanel::Outline => self.json_outline_contents(ui),
                RightPanel::Cards => self.card_pane_contents(ui, actions),
            });
        self.right_panel_width = panel.response.rect.width();
    }
}
```

```rust
impl App {
    /// The one stored card the pane describes: the stored selection when it is a single card still shown, on a
    /// level that is not a JSON level.
    pub(crate) fn pane_card(&self) -> Option<NodeId> {
        let mut stored = self.interaction.selected.iter().filter_map(|c| c.node());
        match (stored.next(), stored.next()) {
            (Some(id), None) if self.json_level.is_none() && self.nodes.contains_key(&id) => Some(id),
            _ => None,
        }
    }

    /// R2: when the pane starts describing another card, the camera brings it into view (`camera.reveal`, eased by
    /// `pan_to` only when it is not fully visible), unless a drag holds it: easing would move the world under the
    /// pointer.
    pub(super) fn track_pane_card(&mut self) {
        let card = self.pane_card();
        if card == self.interaction.pane_card {
            return;
        }
        self.interaction.pane_card = card;
        if let (Some(id), None) = (card, self.interaction.dragging) {
            self.camera.reveal = Some(id);
        }
    }

    /// The pane: the count for several cards, the card's name for one. Tasks 3 and 4 add the sections.
    pub(super) fn card_pane_contents(&mut self, ui: &mut egui::Ui, _actions: &mut Vec<GraphAction>) {
        match self.pane_card() {
            Some(id) => {
                ui.strong(self.accessible_name(id).unwrap_or_default());
            }
            None => {
                ui.label(format!("{} selected", self.selected_stored_count()));
            }
        }
    }
}
```

```rust
/// The rows a layer's widgets queued this pass (`nav_row`, `nav_stop`), with the popup's marks.
pub(crate) struct ListRows {
    pub(crate) rows: Vec<Vec<egui::Id>>,
    opens_on: Option<egui::Id>,
    /// The rows are only a window of the list (`mark_list_partial`): stepping stops at the ends.
    pub(crate) partial: bool,
    page: Option<egui::Id>,
}

/// Reads and clears what this layer's rows queued this pass. Call once per pass, after the rows.
pub(crate) fn take_list_rows(ui: &egui::Ui) -> ListRows {
    let key = list_rows_key(ui);
    ListRows {
        rows: ui.data_mut(|d| d.remove_temp(key)).unwrap_or_default(),
        opens_on: ui.data_mut(|d| d.remove_temp::<Option<egui::Id>>(key.with("opens_on"))).flatten(),
        partial: ui.data_mut(|d| d.remove_temp::<bool>(key.with("partial"))).unwrap_or(false),
        page: ui.data_mut(|d| d.remove_temp::<Option<egui::Id>>(key.with("page"))).flatten(),
    }
}

/// While one of `rows` has focus, Up/Down move it (wrapping unless `partial`), every press counted; returns whether
/// one had focus. With none focused it leaves the keys alone: the card pane's rows (spec R5) use only this.
pub(crate) fn step_focused_row(ui: &egui::Ui, rows: &[Vec<egui::Id>], partial: bool) -> bool {
    let Some(at) = rows.iter().position(|stop| stop.iter().any(|id| ui.memory(|m| m.has_focus(*id)))) else {
        return false;
    };
    // Presses that land in one frame (a slow frame, a key repeat) are each a step.
    let (downs, ups) = ui.input_mut(|i| {
        (
            i.count_and_consume_key(egui::Modifiers::NONE, egui::Key::ArrowDown),
            i.count_and_consume_key(egui::Modifiers::NONE, egui::Key::ArrowUp),
        )
    });
    // Wraps at the ends, unless the rows are only a window of the list (`mark_list_partial`).
    let next = step_index(at, downs as isize - ups as isize, rows.len(), !partial);
    if next != at {
        ui.memory_mut(|m| m.request_focus(rows[next][0]));
    }
    true
}
```

```rust
pub(crate) fn list_row_nav(ui: &mut egui::Ui, interactable: bool) {
    let key = list_rows_key(ui);
    let ListRows { rows, opens_on, partial, page } = take_list_rows(ui);
    let page_changed = ui.data_mut(|d| {
        let last = d.get_temp::<Option<egui::Id>>(key.with("last_page"));
        d.insert_temp(key.with("last_page"), page);
        interactable && last.is_some_and(|last| last != page)
    });
    let just_opened = popup_just_opened(ui.ctx(), key.with("was_open"), interactable) || page_changed;
    if !interactable || rows.is_empty() {
        return;
    }
    if just_opened {
        ui.memory_mut(|m| m.request_focus(opens_on.unwrap_or(rows[0][0])));
        return;
    }
    if step_focused_row(ui, &rows, partial) {
        return;
    }
    // Nothing focused (the focused row went away with a page swap, as in the node menu's Color page, or the popup
    // opened without focus): Down enters at the first row, Up at the last.
    let (down, up) = ui.input_mut(|i| {
        (
            i.consume_key(egui::Modifiers::NONE, egui::Key::ArrowDown),
            i.consume_key(egui::Modifiers::NONE, egui::Key::ArrowUp),
        )
    });
    if down || up {
        let entry = if down { &rows[0] } else { &rows[rows.len() - 1] };
        // egui's own arrow-key focus search would otherwise pick a widget at the end of the pass.
        ui.memory_mut(|m| {
            m.move_focus(egui::FocusDirection::None);
            m.request_focus(entry[0]);
        });
    }
}
```

```rust
    }

        });
    }
```
