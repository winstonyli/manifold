## Verified 2026-10-17

- **Restore touches own file paths on the UI thread.** `exists` (`session_sync.rs:702`, only when the node has a URL), `fs::metadata` for a Download's size (`session_sync.rs:754`, `fetched.rs:487`) and the json insert's inline read. *Why parked:* by decision; the answer picks placeholder vs real card, so the fix needs a "checking" card state and a worker result message. *Trigger:* a restore that freezes on a slow own-network share. *Start with:* the Download byte count (show 0, a worker fills it in). *Status:* parked. (The hostile case, a crafted import naming a UNC path, is closed: foreign imports drop every `path`.)
- **Jar and redirect-fetch writes fsync on the UI thread.** `Jar::save` (`jar.rs:350`) via `App::save_jar` (`jar_defs.rs:632`); the `ViewToHost::JsonBody` handler calls `redirect_fetch::save` (`event_loop.rs:1573`). *Why parked:* small stalls, no report. *Trigger:* a measured frame hitch on a slow disk. *Fix:* hand the body to the fetcher worker; write jars on a writer thread or debounce. *Status:* parked.
- **A2 `reported_url` flash.** The guard (`event_loop.rs:1393`) suppresses the old URL only for 2 s after `navigate_tab`. Traced 2026-10-17: `finish_swap` (`view_modes.rs:286`) removes the old node, so the old host's channel is dropped and an engine swap cannot deliver a stale report; the only open path is a slow navigation whose old-URL report lands after the 2 s window. No flash seen. *Trigger:* a seen stale URL after a slow navigation. *Fix:* key suppression on a navigation id, not a timer. *Status:* parked.
- **Dot grid draws one circle per dot every frame.** `paint_dot_grid` (`graph_ui.rs:2018`), about 6k dots at low zoom on a large view. *Trigger:* a profile showing it. *Fix:* one batched mesh. *Status:* parked. Not measured: the egui 0.36 tessellation probe was abandoned (no `Context::run` in this version); measure in the app with samply when it matters.

- **Switch the surface to `Immediate` (`gpu::PRESENT_MODE`).** The cap and the page-frame redraw are in; with the constant at `Immediate` key to screen is 33.5 ms median against 100.0 (`keylat-cap3`, release), idle CPU 4.3-4.5% against 3.5% (`idlecap`). *Why parked:* waiting for the decision to flip. Tearing: none seen by eye and PresentMon shows `Composed: Flip`, `AllowsTearing=0` (README); another monitor and fullscreen are unchecked; `frame_interval` reads `current_monitor` once a second. *Trigger:* the user decides to flip. *Evidence:* `event_loop.rs` `about_to_wait`, `on_view_wake`; `docs/runs.md` `keylat-cap3`, `idlecap` (2026-10-17). *Status:* parked.
