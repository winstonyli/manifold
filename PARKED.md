Traced 2026-10-17: `finish_swap` (`view_modes.rs:286`) removes the old node, so the old host's channel is dropped and an engine swap cannot deliver a stale report; the only open path is a slow navigation whose old-URL report lands after the 2 s window. Not measured: the egui 0.36 tessellation probe was abandoned (no `Context::run` in this version); measure in the app with samply when it matters.

- **`Immediate` present mode: unchecked cases.** It is on (`gpu::PREFERRED_PRESENT_MODE`, README "View latency, measured").
